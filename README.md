# Issuer desk
Open review.html locally in Chrome or Edge. Choose note 05, compare Exact label and Local model + rules, then confirm the highlighted link. Reload to verify persistence and choose Reopen to record a reversal. Try note 03 for a valid issuer the model misses and note 07 for conflicting labels. The source lines, directory IDs and notes are synthetic.

## Reproduce
Python 3, standard library only. Run `python demo.py` in this folder. It evaluates all 13 cases, writes results.csv, prints separate counts and builds review.html. No cloud service, install, credential or model download. model.py contains the separate nearest-neighbour adapter and seven labelled training examples. demo.py contains the directory, source fixtures, expected labels, exact checks and comparative evaluation. The HTML ships with precomputed results from that run. The browser handles review and confirmation.

## Limits
One invented English-language excerpt per note, three case-sensitive directory names, no ingestion of PDFs or holdings. The training sentences and evaluation set share an author. Exact labels are deliberately narrow. The prose matcher discards word order and can miss a clear issuer or propose a wrong one. Negation checks are illustrative, not comprehensive. Unknown prose names are not resolved. Ambiguous roles and multi-series filings need an analyst. A hold cannot be overridden in this demo. The event history is single-browser, editable local storage, not an authenticated production audit log. Clear the issuer-desk-synthetic-v1 local-storage key to reset. No holdings, cash values, trades, external requests or financial decisions.

## Compare versions
Follow the amendment link in the demo. A, B and C are independent alternatives to the same confirmed synthetic original. A changes the guarantor, B requires a fresh issuer decision and C lacks issuer evidence. Confirm B, switch versions and reopen B to inspect the history. Keep desk.css and amendment-view.js next to review.html. Run python -m unittest test_amendments to verify the comparison logic.

A guarantor-only change skips issuer review only when each changed line is a simple guarantor label naming a directory entity. Extra wording, such as a reference to revised issuer terms in an annex, goes to research.

## Public filing comparison
Run `python public_eval.py` to reproduce public-results.csv. public-excerpts.json records the eight pre-scoring labels, quoted spans, source locators and direct SEC URLs. Table cells were joined with whitespace. Clauses are deliberately short where indicated. HOLD means the shown words do not identify the issuer. All routes see identical excerpts and the same six-name directory, including distractors. Exact and assisted reuse the demo implementation with the public directory. The phrase route extends exact labels with issued by / obligations of immediately before one known name. It retains the conservative multi-name prose guard. No alias stripping, threshold adjustment or training on these labels. Codex selected and labelled the excerpts, with no independent adjudicator. This convenience sample measures role identification given a passage, not retrieval or production accuracy.

## Starting from a filing URL
For each of the same eight SEC URLs, Codex searched the indexed full document for the literal Issuer: label using the web reader. It kept the first returned line beginning with that label and its first nonempty value cell. No row returned means hold, not proof that the label is absent. The URL, web-reader line or PDF page locator, captured row and document-level expected issuer are in filing-search.json. P6 and P8 should hold on their short excerpts but have identifiable issuers at document level. PDF page locators are zero-based.
Run python filing_eval.py to reproduce filing-results.csv offline. The local script scores the saved search results; it does not download or parse full filings. The exact baseline resolved two of eight filings. Five more resolved after stripping a trailing parenthesized quoted alias or pronoun pair before exact lookup. No wrong issuer was suggested. This exploratory normalization was designed after inspecting this small set. The search used one row per filing and did not check for competing issuer rows in other series. It cannot support unattended updates.

## Optional browser tests
With Node, Playwright, Chrome and Edge available, run node e2e.cjs from the extracted package. The suite opens review.html offline in isolated desktop and mobile-width browser contexts.

## Additional issuer and series tests
Run python extended_eval.py. Eight additional SEC filings cover four new issuers with a supplied directory including parent names. Search terms explicitly targeted issuer labels; this is a convenience sample. Saved rows in new-issuers.json normalize only layout markup and whitespace. The scoring rules were unchanged. new-issuer-results.csv reports each prediction. series-stress-results.csv isolates first-row selection given a requested series B and synthetic A/B issuer rows in both orders. It tests the scope assumption, not extraction from complete multi-series documents. Two wrong suggestions out of eight are expected evidence of that limitation.
